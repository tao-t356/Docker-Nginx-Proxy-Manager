# Nginx Proxy Manager 一键管理工具
作者: Facker668 | Email: tao356334@gmail.com

### 🚀 快速开始
在你的 VPS 执行以下命令：
\`\`\`bash
wget -qO n https://raw.githubusercontent.com/tao-t356/Docker-Nginx-Proxy-Manager/main/install.sh && bash n
\`\`\`

### 💡 快捷功能
安装完成后，直接在终端输入 \`npm\` 即可呼出管理菜单。

### 🛠 功能介绍
1. **自动安装 Docker**: 适配 Ubuntu/Debian/CentOS。
2. **部署 NPM 面板**: 自动处理纯 IPv6 环境下的网络问题。
3. **一键清理**: 干净地卸载服务，不残留垃圾文件。
